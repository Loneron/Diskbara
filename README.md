## 🌿 Что такое Diskbara?

**Diskbara** — бесплатный анализатор дискового пространства с открытым исходным кодом, разрабатываемый в первую очередь для Windows. В дальнейшем планируется поддержка Linux.

Его задача — помочь разобраться, куда пропадает свободное место на компуктере, найти большие файлы и папочки, а в будущем — предложить понятные и безопасные способы освобождения пространства.

Diskbara создаётся для тех, кто хочет контролировать использование диска, не рискуя важными данными.

Никакой загадочной очистки, непонятных действий или удаления файлов без разрешения пользователя.

И всё это в компании дружелюбной капибары. 🦫💚

## ✨ Планируемые возможности

### 📁 Анализ дискового пространства

- Сканирование выбранных папок и дисков.
- Подсчёт количества файлов и каталогов.
- Определение размера файлов и папок.
- Поиск наиболее крупных файлов.
- Анализ распределения занятого пространства.

### 📊 Наглядная визуализация

- Удобное представление результатов сканирования.
- Диаграммы использования дискового пространства.
- Сортировка файлов и папок по размеру.
- Быстрый переход к интересующим каталогам.

### 🛡️ Безопасность

- Сканирование в режиме read-only.
- Отсутствие автоматического удаления файлов.
- Предварительный просмотр планируемых действий.
- Подтверждение потенциально опасных операций.
- Разделение рекомендаций по уровням риска.
- Объяснение причин каждой рекомендации.

### 🧹 Безопасная очистка

В дальнейшем планируется система рекомендаций, которая поможет находить потенциально ненужные файлы.

Перед выполнением действий пользователь сможет увидеть:

- Какие файлы предлагается удалить.
- Сколько места потенциально освободится.
- Почему эти файлы были выбраны.
- Какие риски связаны с удалением.

**Окончательное решение всегда остаётся за пользователем.**


### 💻 Поддерживаемые платформы

**Windows** — основная целевая платформа Diskbara.

В дальнейшем планируется поддержка **Linux**.

**macOS** — поддержка этой операционной системы в ближайших планах отсутствует. Возможность её реализации в будущем не исключается, но никаких сроков или обязательств по её добавлению нет.

> [!NOTE]
> На данный момент Diskbara находится в активной разработке. Публичные версии приложения пока недоступны ни для одной платформы.

## 🛠️ Технологии

| Компонент | Технология |
|---|---|
| Ядро приложения | Go |
| Десктопный фреймворк | Wails v3 |
| Пользовательский интерфейс | React |
| Язык frontend | TypeScript |
| Инструмент сборки frontend | Vite |
| Локальное хранение данных (планируется) | SQLite |

### Почему именно эти технологии?

**Go** используется для разработки независимого ядра приложения и работы с файловой системой.

**Wails** позволяет создавать настольные приложения, объединяя Go и современные веб-технологии.

**React + TypeScript** используются для создания удобного и интерактивного интерфейса.

**SQLite** рассматривается для локального хранения результатов анализа и настроек приложения.

## 🔐 Принципы разработки

Безопасность пользовательских данных — один из главных приоритетов Diskbara.

### 1. Read-only по умолчанию

Анализ дискового пространства должен выполняться без изменения пользовательских файлов.

### 2. Никаких скрытых действий

Приложение не должно удалять или перемещать файлы без явного согласия пользователя.

### 3. Прозрачные рекомендации

Пользователь должен понимать, почему определённый файл считается потенциально ненужным.

### 4. Минимальные привилегии

Diskbara должна работать без повышенных прав там, где это возможно.

### 5. Безопасность важнее скорости

При разработке приоритет отдаётся предсказуемости, надёжности и защите данных.

### 6. Контроль пользователя

Все потенциально опасные действия должны оставаться под контролем пользователя.
